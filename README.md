# Счёт 108 (мультиплеер)

Игра идёт в реальной жизни, а приложение считает очки на телефонах всех игроков.

## Как играть

1. Один создаёт комнату и сообщает код (или отправляет ссылку).
2. Остальные заходят по коду и попадают в список игроков.
3. Создатель нажимает «Начать игру».
4. После каждого раунда каждый вводит только свои очки. Счёт у всех виден сразу.
5. У кого набралось 108 и больше, тот проиграл: у всех на экране появляется «проиграл», его карточка закрывается. Остальные играют дальше.
6. Когда остаётся один игрок, у всех на экране появляется победитель с короной. Создатель может нажать «Новая игра».

Нюансы: если вписал очки неверно, пока остальные не записали, нажми «Исправить». Закрыл раунд дамой? Впиши минус (пики −40, остальные масти −20).

## Запуск локально

    npm install
    npm start

Откроется на http://localhost:3000

## Деплой на Render

1. Залей содержимое папки в корень репозитория на GitHub (server.js, package.json, папка public/).
2. На render.com: New → Web Service → репозиторий. Runtime: Node. Build Command: `npm install`. Start Command: `npm start`. Plan: Free.
3. Адрес вида `https://schet108-xxxx.onrender.com` открывают на всех телефонах.

## Бесплатный тариф Render

Сервер засыпает после 15 минут без заходов, первый заход после паузы грузится около минуты. Файлы на нём при перезапуске пропадают, поэтому у каждого игрока в телефоне хранится копия комнаты, и она сама восстанавливается на сервере, когда кто-то из игроков откроет приложение. Для надёжного хранения подключите Render Disk и задайте переменную `DATA_DIR` на путь диска.

## Обновление

После правок в `public/` увеличьте версию в первой строке `public/sw.js` (`schet108-v3` → `schet108-v4`).
