# Счёт 108 (мультиплеер)

Приложение для подсчёта очков в карточной игре 108. Дизайн и логика без изменений. Добавлен сервер, поэтому столы видны всем игрокам в реальном времени. Записывать очки может только создатель стола.

## Запуск локально

    npm install
    npm start

Откроется на http://localhost:3000

## Деплой на Render

1. Загрузите содержимое этой папки в корень репозитория на GitHub (server.js, package.json, папка public/).
2. На render.com: New → Web Service → выберите репозиторий.
3. Runtime: Node. Build Command: `npm install`. Start Command: `npm start`. Plan: Free.
4. Нажмите Deploy. Адрес вида `https://schet108-xxxx.onrender.com` откройте на всех телефонах и добавьте на главный экран.

## Важно про бесплатный тариф

- Сервер засыпает после 15 минут без заходов, первый заход после паузы грузится около минуты.
- Файлы на бесплатном тарифе не сохраняются при перезапуске. Чтобы столы не пропадали, приложение у создателя стола хранит копию и само восстанавливает его на сервере при следующем заходе. Для надёжного хранения подключите Render Disk (платно), смонтируйте его и задайте переменную `DATA_DIR` на путь диска.

## Режим «только этот телефон»

В `public/config.js` поставьте `server: false`.

## Фото-подсчёт карт

Работает как раньше: ключ Anthropic вводится в настройках приложения на телефоне и хранится только там.

## Обновление

После правок в `public/` увеличьте версию в первой строке `public/sw.js` (`schet108-v2` → `schet108-v3`).
